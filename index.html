PDFMerge
Private PDF composition

Merge PDFs and images.

Combine files, reorder pages, and add watermarks. Export locally, with no uploads, accounts, or server processing.

  • No uploads
  • PDFs + images
  • Watermarks

Choose PDFs or images

Drag and drop, or browse. Browse your device. PDF, JPG, PNG, GIF & WebP.

    Page size

    Select the output paper size. Images and content will be scaled appropriately to fit the selected size.

    Images

    Image Processing Options

    Adds the image name and EXIF details including GPS and date if available.

    Adds an image number in the bottom right corner.

    Adds the unique SHA-256 hash value for verification.

    These options only work when the image layout is set to Default Margins, not Fit or Cover.

    Watermark

    Watermark Configuration Options

    No image chosen. The image stays in this tab and is never uploaded or saved.

    Adds a text or image watermark to all PDF pages including images and existing documents

    The text that will appear as a watermark on each page

    Choose the color of the watermark text

    Controls transparency: 0 is fully transparent, 1 is fully opaque

    Angle of rotation for the watermark text in degrees

    Size multiplier for the watermark text

    When enabled, covers the entire page with repeated watermarks for copy protection

    Use {n}, {total}, {file}, {date}, {time}; {n:3} pads; {date:DD/MM/YYYY} formats.

    Header & footer

    Header text overlaps page numbers.

    Enter 0–50 mm in 0.5 mm steps.

    Footer text overlaps page numbers.

    Enter 0–50 mm in 0.5 mm steps.

    Adds a blank page after an odd-page card, except the last card.

    Enter a whole number of 1 or greater.
